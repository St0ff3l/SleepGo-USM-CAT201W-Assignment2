# SleepGo - Company Homepage

This project is a responsive company homepage for "SleepGo" (Software House), developed for USM CAT201 Assignment 2. It is built using **React.js** for the frontend.

## Project Structure

- **client/**: React.js frontend application (Vite).

## Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

## Installation

1.  **Clone the repository** (if applicable) or download the source code.
2.  **Install dependencies**:

    ```bash
    cd client && npm install
    ```

## Running the Application

To run the client:

1.  Open a terminal in the root directory.
2.  Run the following command:

    ```bash
    npm run dev
    ```

This will start:
-   **Frontend**: http://localhost:5173

## Features

-   **Responsive Design**: Works on desktop and mobile devices.
-   **Static Content**: Company information (Mission, Vision, Services, Team) is managed directly in the React component.
-   **Single Page Layout**: Smooth navigation between sections.

## Customization

-   **Content**: Edit `client/src/App.jsx` to update company details, services, and team members.
-   **Images**: Replace the placeholder image URLs in `client/src/App.jsx` with actual team photos.
-   **Styles**: Modify `client/src/App.css` to change the look and feel.
